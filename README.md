I am a Computer Science student at Sunway University who enjoys building practical systems across cloud computing, web development, networking, cybersecurity, backend development, distributed systems, IPv6/BGP, and homelab infrastructure.

- Building with: Python, Java, Rust, JavaScript, TypeScript, Scala, Spring Boot, Docker, Linux, Cloudflare, AWS, and Proxmox
